# Eurovision Scraper BeautifulSoup

This project performs web scraping using **Python** and **BeautifulSoup** to collect Eurovision Song Contest results from the past decade.  
It focuses on **Israel's performance** in the contest and presents **data-driven insights and trends** over the years.

## Features
- Web scraping of Eurovision results from official sources
- Data cleaning and structuring with Python
- Analysis of Israel's ranking and points per year
- Basic visualizations of trends

## Tools & Technologies
- Python
- BeautifulSoup
- Pandas
- Matplotlib
